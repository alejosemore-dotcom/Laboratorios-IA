## Laboratorios incluidos

### 1. Clasificación de tiquetes con OpenRouter

Implementación de una solución para clasificar tiquetes institucionales mediante:

- OpenRouter
- FastMCP
- PostgreSQL
- Python
- WSL2

### 2. Inteligencia artificial local con Open WebUI y Ollama

Implementación de un modelo de lenguaje ejecutado localmente mediante:

- Docker Desktop
- Open WebUI
- Ollama
- Modelo qwen2.5:0.5b
- Procesamiento mediante CPU
